# Knowledge pack (RAG manifest stub)

Populate this directory with:

- **Citation cards** — compact JSON with DOI, arXiv id, and a 3–5 sentence summary of methods relevant to the analysis.
- **CMS-specific snippets** — object IDs, pileup mitigation recipes, golden JSON pointers (paths only; no tokens).
- **`manifest.json`** — list of files with SHA256 checksums for reproducible retrieval.

External doc links should mirror what appears on the ML4SCI / CMS project pages you cite in proposals.
